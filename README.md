# Power Flow Analysis Using Gauss-Seidel and MIT Formulation

## Overview
This project focuses on power flow (load flow) analysis of electrical power systems using MATLAB. The analysis includes the implementation of the Gauss-Seidel iterative method and MIT formulation techniques to evaluate bus voltages, power flow, line currents, and complex power behavior in interconnected power networks. The project investigates system operating conditions, convergence behavior, and power transfer characteristics through engineering computation and numerical analysis.

## Features
- Power flow analysis using Gauss-Seidel method
- MIT formulation implementation
- Y-bus matrix modeling
- Bus voltage calculation
- Complex power and line flow analysis
- Iterative numerical computation
- MATLAB-based engineering simulation
